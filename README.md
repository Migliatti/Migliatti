## ◈ Sobre

Trabalho com implementação e suporte de TI e curso Ciência da Computação.
No trabalho, investigo incidentes, analiso logs e automatizo rotinas.
Nos projetos, construo aplicações web e exploro formas de desenvolver
software com agentes de IA.

Meus interesses passam por sistemas, automação e astronomia.
Aqui eles aparecem em aplicações com regras de negócio, experiências
interativas e ferramentas para agentes.

## ◈ Projetos em órbita

### [LabReserve](https://github.com/Migliatti/labreserve)
Sistema de reservas de laboratórios e equipamentos, com consulta de
disponibilidade, detecção de conflitos, cancelamento e histórico de eventos.

Arquitetura em camadas, gravação transacional de reservas e eventos,
testes de domínio, integração, API e interface.

**TypeScript · React · SQLite · Playwright**

[Estudo de caso](https://migliatti.vercel.app/pt/projetos/labreserve)

### [Kepler Lab](https://github.com/Migliatti/kepler-lab)
Experiência web 3D para explorar a Via Láctea, com destinos astronômicos
e conteúdo científico curado.

Combina navegação interativa, testes unitários e recursos de
acessibilidade, como movimento reduzido e alto contraste.

**TypeScript · React · Three.js · Vite**

[Explorar aplicação](https://kepler-lab-gamma.vercel.app/) ·
[Estudo de caso](https://migliatti.vercel.app/pt/projetos/kepler-lab)

### [Grimoire](https://github.com/Migliatti/grimoire)
Catálogo open source de skills e workflows reutilizáveis para agentes
de IA, com uma implementação canônica e integração por plataforma.

Inclui testes de contratos em Python e avaliações comportamentais
com cenários e registros de resultados.

**Python · Markdown · Claude Code · Codex**

[Estudo de caso](https://migliatti.vercel.app/pt/projetos/grimoire)
